**Carrier:** `POST /v1/exchange` (encrypted binary).

**Permission:** Owner only.

Authorize an agent with explicit permissions and limits. The same command is available over [WebSocket](/api/websocket).

<Note>Configure `client` and the example inputs using [SDK integration](/quickstart). Examples show typed SDK values, not a plaintext HTTP JSON body.</Note>

<RequestExample>
```ts SDK request
const response = await client.request({ id: ctx.id, epoch: ctx.epoch, expiresAt: ctx.expiresAt,
    command: { kind: 'grant', grant: {
      key: ctx.agentPublicKey, methods: READ | TRADE | CANCEL, market: ctx.market,
      maximumLots: 2n, maximumFee: 1n, maximumOrders: 10n,
      expiresAt: ctx.agentExpiresAt } } });
```
</RequestExample>

## Request fields

The client supplies the configured domain, account, policy, signer and verified
session binding, and signs the canonical [envelope](/api/authentication).

<ParamField body="id" type="Uint8Array (32 bytes)" required>
  Nonzero private request ID. Retain it for an exact retry; use a distinct ID for a different intent.
</ParamField>

<ParamField body="epoch" type="bigint (u64)" required>
  Current account authority epoch.
</ParamField>

<ParamField body="expiresAt" type="bigint (u64)" required>
  Expiry timestamp in milliseconds, within the verified channel and configured authentication limits; not a validity duration.
</ParamField>

<ParamField body="command.kind" type="&quot;grant&quot;" required>
  Command discriminator.
</ParamField>

<ParamField body="command.grant" type="Grant" required>
  Scoped Cinder agent terms.
  <Expandable title="Grant fields">
<ParamField body="key" type="Uint8Array (32 bytes)" required>
  Separate valid Ed25519 agent public key, not owner key.
</ParamField>

<ParamField body="methods" type="number" required>
  Nonzero bitmask: READ=1, TRADE=2, CANCEL=4, no other bits.
</ParamField>

<ParamField body="market" type="Uint8Array (32 bytes)" required>
  The trading/cancellation market. READ grants account-wide visibility across markets.
</ParamField>

<ParamField body="maximumLots" type="bigint (u64)" required>
  Positive maximum absolute lots per admitted order.
</ParamField>

<ParamField body="maximumFee" type="bigint (i128)" required>
  Nonnegative maximum fee per lot in quote atoms.
</ParamField>

<ParamField body="maximumOrders" type="bigint (u64)" required>
  Positive lifetime accepted-order budget in this epoch.
</ParamField>

  <ParamField body="expiresAt" type="bigint (u64)" required>
  Agent-grant expiry timestamp in milliseconds, within the configured maximum grant duration. Separate from this request's authentication expiry.
</ParamField>
  </Expandable>
</ParamField>

## Response fields

The result uses the shared [receipt fields](/api/lifecycle#shared-receipt-fields).
The fields below are most relevant to this method.

<ResponseField name="kind" type="&quot;receipt&quot;" required>
  Response discriminator.
</ResponseField>

<ResponseField name="id" type="Uint8Array (32 bytes)" required>
  ID of this recorded command, matching the request's `id`.
</ResponseField>

<ResponseField name="outcome" type="Outcome" required>
  `rejected`, `accepted`, `dispatched`, `acknowledged`, `partial`, `complete` or `unknown`. See [lifecycle](/api/lifecycle).
</ResponseField>

## Behavior

The grant records the permitted methods, market, expiry and order limits. An exact order retry does not consume another accepted-order budget unit. An existing agent key's grant cannot be replaced within the same authority epoch.

**READ is account-wide across markets.** The market field restricts trading and cancellation, not the account information available to a READ agent. Only that agent's own grant is visible in its grant-directory view.

Agents have no payout, recipient-change, leverage, redelegation or administrator authority. See [agent permissions](/guides/agents). Import `READ`, `TRADE` and `CANCEL` from the SDK for the example.
