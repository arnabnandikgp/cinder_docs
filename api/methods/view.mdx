**Carrier:** `POST /v1/exchange` (encrypted binary).

**Permission:** Owner or current READ agent.

Read a compact account snapshot. The same command is available over [WebSocket](/api/websocket).

<Note>Configure `client` and the example inputs using [SDK integration](/quickstart). Examples show typed SDK values, not a plaintext HTTP JSON body.</Note>

<RequestExample>
```ts SDK request
const response = await client.request({ id: ctx.id, epoch: ctx.epoch, expiresAt: ctx.expiresAt,
    command: { kind: 'view' } });
```
</RequestExample>

<ResponseExample>
```ts Decoded view
({
  kind: 'view',
  epoch: ctx.epoch,
  cash: 100n,
  funding: 0n,
  held: 0n,
  positions: [],
  operations: [],
})
```

```ts Encrypted application error
({ kind: 'error', code: 'unauthorized' })
```
</ResponseExample>

## Request fields

The client supplies the configured domain, account, policy, signer and verified
session binding, and signs the canonical [envelope](/api/authentication).

<ParamField body="id" type="Uint8Array (32 bytes)" required>
  Nonzero ID for this read request. A view does not create a trading or payout operation.
</ParamField>

<ParamField body="epoch" type="bigint (u64)" required>
  Current account authority epoch.
</ParamField>

<ParamField body="expiresAt" type="bigint (u64)" required>
  Expiry timestamp in milliseconds, within the verified channel and configured authentication limits; not a validity duration.
</ParamField>

<ParamField body="command.kind" type="&quot;view&quot;" required>
  Command discriminator.
</ParamField>

## Response fields

The example uses illustrative quote atoms and configured IDs, not live venue data. See [account amounts](/guides/accounts) for the meaning of cash, funding and reservations.

<ResponseField name="kind" type="&quot;view&quot;" required>
  Compact account view discriminator.
</ResponseField>

<ResponseField name="epoch" type="bigint (u64)" required>
  Current account authority epoch.
</ResponseField>

<ResponseField name="cash" type="bigint (i128)" required>
  Signed settled cash, in quote atoms.
</ResponseField>

<ResponseField name="funding" type="bigint (i128)" required>
  Signed recognized unsettled funding, in quote atoms.
</ResponseField>

<ResponseField name="held" type="bigint (i128)" required>
  Explicit reservations, in quote atoms. Not the entire risk requirement.
</ResponseField>

<ResponseField name="positions" type="Position[]" required>
  Configured market ID, precision version, signed lots and remaining signed basis. See [positions](/api/reads/positions).
</ResponseField>

<ResponseField name="operations" type="Uint8Array[]" required>
  Retained private operation IDs. Query [operation](/api/methods/operation) for receipts.
</ResponseField>

## Behavior

The view returns the account epoch, settled cash, recognized unsettled funding, explicit reservations, positions and retained operation IDs.

For marked equity and margin information, use [account reads](/api/reads/account). A compact view is not a withdrawable-funds quote or a proof of backing.

## Errors and reconciliation

See [errors](/api/errors) for response codes and [lifecycle](/api/lifecycle)
for delivery failures, receipts and retries. Keep the original operation ID when
reconciling an uncertain result.
