**Carrier:** `POST /v1/exchange` (encrypted binary).

**Permission:** Owner or scoped TRADE agent.

Place a bounded order and follow its execution. The same command is available over [WebSocket](/api/websocket).

<Note>Configure `client` and the example inputs using [SDK integration](/quickstart). Examples show typed SDK values, not a plaintext HTTP JSON body.</Note>

<RequestExample>
```ts SDK request
const response = await client.request({ id: ctx.id, epoch: ctx.epoch, expiresAt: ctx.expiresAt,
    command: { kind: 'order', market: ctx.market, lots: 2n,
      minimum: 90n, maximum: 110n, fee: 1n, tif: 'IOC',
      reduceOnly: false, goodUntil: ctx.goodUntil } });
```
</RequestExample>

<ResponseExample>
```ts Decoded receipt

```

## Request fields

The client supplies the configured domain, account, policy, signer and verified
session binding, and signs the canonical [envelope](/api/authentication).

<ParamField body="id" type="Uint8Array (32 bytes)" required>
  Nonzero private request ID. Retain it for an exact retry; use a distinct ID for a different intent.
</ParamField>

<ParamField body="epoch" type="bigint (u64)" required>
  Current account authority epoch.
</ParamField>

<ParamField body="expiresAt" type="bigint (u64)" required>
  Expiry timestamp in milliseconds, within the verified channel and configured authentication limits; not a validity duration.
</ParamField>

<ParamField body="command.kind" type="&quot;order&quot;" required>
  Command discriminator.
</ParamField>

<ParamField body="command.market" type="Uint8Array (32 bytes)" required>
  Configured market ID. Its metadata and the approved policy determine the trading units; see [markets](/api/reads/markets).
</ParamField>

<ParamField body="command.lots" type="bigint (i64)" required>
  Nonzero: positive buy, negative sell.
</ParamField>

<ParamField body="command.minimum" type="bigint (u64)" required>
  Positive inclusive lower execution-price bound, in ticks.
</ParamField>

<ParamField body="command.maximum" type="bigint (u64)" required>
  Positive inclusive upper execution-price bound, in ticks; must be at least `minimum`.
</ParamField>

<ParamField body="command.fee" type="bigint (i128)" required>
  Nonnegative maximum quote-atom fee per lot, not percentage or total fee. `abs(lots) × fee` must fit i128.
</ParamField>

<ParamField body="command.tif" type="&quot;GTC&quot; | &quot;ALO&quot; | &quot;IOC&quot;" required>
  Good-til-cancelled, add-liquidity-only or bounded immediate-or-cancel.
</ParamField>

<ParamField body="command.reduceOnly" type="boolean" required>
  Must not open/reverse the private customer's position.
</ParamField>

<ParamField body="command.goodUntil" type="bigint (u64)" required>
  Latest permitted dispatch time in milliseconds, unchanged on retry. It does not automatically cancel an already dispatched resting order.
</ParamField>

## Response fields

The result uses the shared [receipt fields](/api/lifecycle#shared-receipt-fields).
The fields below are most relevant to this method.

<ResponseField name="kind" type="&quot;receipt&quot;" required>
  Response discriminator.
</ResponseField>

<ResponseField name="id" type="Uint8Array (32 bytes)" required>
  ID of this recorded command, matching the request's `id`.
</ResponseField>

<ResponseField name="outcome" type="Outcome" required>
  `rejected`, `accepted`, `dispatched`, `acknowledged`, `partial`, `complete` or `unknown`. See [lifecycle](/api/lifecycle).
</ResponseField>

<ResponseField name="filled" type="bigint (i64)" required>
  Actual attributed signed lots, not requested quantity.
</ResponseField>

<ResponseField name="feeCap" type="bigint (i128)" required>
  Total authorized trading-fee cap: `abs(lots) × fee`. Actual charged fees appear in [fills](/api/reads/fills).
</ResponseField>

<ResponseField name="possiblyExposed" type="boolean" required>
  Whether an action or signature may have reached external execution. This is not confirmation of a fill or payment.
</ResponseField>

## Behavior

The receipt records the declared total fee cap, `abs(lots) × fee`, and actual signed filled lots. Charged trading fees appear in [fills](/api/reads/fills).

Admission checks margin, pending outcomes and available pool resources before reserving funds. Agent size, fee and accepted-order limits also apply. IOC may fill partially or not at all.

`goodUntil` is the latest permitted dispatch time. It does **not** cancel an already dispatched GTC or ALO order when that time arrives. Use [cancel](/api/methods/cancel) for a resting order; its reservations remain until execution is reconciled.

## Errors and reconciliation

See [errors](/api/errors) for response codes and [lifecycle](/api/lifecycle)
for delivery failures, receipts and retries. Keep the original operation ID when
reconciling an uncertain result.
