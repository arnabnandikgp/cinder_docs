**Carrier:** `POST /v1/exchange` (encrypted binary).

**Read family:** `fills` · **Permission:** owner or current READ agent.

Your attributed fills, execution values and fees. Results belong to your account. The query supports HTTP and
[WebSocket](/api/websocket), including subscriptions.

<Note>Configure `client` and the example inputs using [SDK integration](/quickstart). Examples show typed SDK values, not a plaintext HTTP JSON body.</Note>

<RequestExample>
```ts SDK request
const response = await client.request({
  id: ctx.id,
  epoch: ctx.epoch,
  expiresAt: ctx.expiresAt,
  command: {
    kind: 'read',
    query: { family: 'fills', limit: 32 },
  },
});
```
</RequestExample>

<ResponseExample>
```ts Decoded page

    },
```

</ResponseExample>

## Request fields

Use the configured [client and envelope](/api/authentication). Each request supplies
`id`, current `epoch` and authentication `expiresAt`, as shown in the example.

<ParamField body="command.kind" type="&quot;read&quot;" required>
  Read-command discriminator.
</ParamField>

<ParamField body="command.query.family" type="&quot;fills&quot;" required>
  Selects this account-data family.
</ParamField>

<ParamField body="command.query.limit" type="number" required>
  Integer from 1 to 64 rows. The example requests 32.
</ParamField>

<ParamField body="command.query.cursor" type="Uint8Array (40 bytes)">
  Omit or use all-zero bytes to start. For another page, use the prior page’s `next` under the same snapshot revision.
</ParamField>

## Behavior

This family contains confirmed ordinary trading fills allocated to your account, with duplicate reports counted once. An acknowledgement or requested quantity is not a fill. Reports that are unverified or not yet allocated to your account are excluded.

Positive `lots` means a buy; negative `lots` means a sell. A positive `fee` is a charge and a negative fee is a rebate. The fee is the actual allocated amount, not the order's fee cap.

Liquidation, ADL and restoration changes are reflected in [account movements](/api/reads/movements) and current positions. This family is not a complete history of those forced position changes.

## Paging and errors

See [paging](/api/reads/paging) for cursors, revisions and missing values, and
[errors](/api/errors) for response codes. Reconnect and fetch a new snapshot after
a subscription closes.
