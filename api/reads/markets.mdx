**Carrier:** `POST /v1/exchange` (encrypted binary).

**Read family:** `markets` · **Permission:** owner or current READ agent.

Market units, order modes and leverage caps. Results belong to your account. The query supports HTTP and
[WebSocket](/api/websocket), including subscriptions.

<Note>Configure `client` and the example inputs using [SDK integration](/quickstart). Examples show typed SDK values, not a plaintext HTTP JSON body.</Note>

<RequestExample>
```ts SDK request
const response = await client.request({
  id: ctx.id,
  epoch: ctx.epoch,
  expiresAt: ctx.expiresAt,
  command: {
    kind: 'read',
    query: { family: 'markets', limit: 32 },
  },
});
```
</RequestExample>

<ResponseExample>
```ts Decoded page

  family: 'markets',
  revision: snapshotRevision,

      denominator: 1n, modes: 7, leverageCap: 20_000n,
    },

})
```

</ResponseExample>

## Request fields

Use the configured [client and envelope](/api/authentication). Each request supplies
`id`, current `epoch` and authentication `expiresAt`, as shown in the example.

<ParamField body="command.kind" type="&quot;read&quot;" required>

</ParamField>

<ParamField body="command.query.family" type="&quot;markets&quot;" required>
  Selects this account-data family.
</ParamField>

<ParamField body="command.query.limit" type="number" required>
  Integer from 1 to 64 rows. The example requests 32.

## Behavior

Use the returned `market` ID in order and leverage commands. `precision` and `quotePrecision` identify unit versions, not decimal counts. Conversion is `lots × ticks × numerator / denominator` in quote atoms, subject to the market's exactness rules.

Asset labels, token decimals and display formatting must come from your integration configuration; they are not fields in this response. These rows do not supply live prices, candles or orderbook depth.

A supported order mode does not guarantee an order will pass account permissions, margin or current risk checks. An absent `leverageCap` is unavailable information, not permission to select unlimited leverage.

## Paging and errors

See [paging](/api/reads/paging) for cursors, revisions and missing values, and
[errors](/api/errors) for response codes. Reconnect and fetch a new snapshot after
a subscription closes.
