---
title: "Private reads and paging"
description: "Read account snapshots and traverse retained history."
---

All ten read families use signed `{ kind: 'read', query: { family, limit, cursor? } }` requests. Owners and current READ agents can read the bound account. Reads do not change balances or consume an agent's accepted-order budget.

| Field | Meaning |
| --- | --- |
| `family` | `account`, `positions`, `operations`, `openOrders`, `fills`, `funding`, `movements`, `grants`, `markets` or `updates`. |
| `limit` | Integer from 1 to 64 rows. |
| `cursor` | Optional 40-byte cursor. Omitted or all-zero starts a snapshot. |
| `revision` | A commitment to the permitted rows and query, not a global activity counter. |
| `next` | The next cursor. All-zero means no more retained rows. |
| `evaluatedAt` | Cinder's evaluation timestamp in milliseconds. |
| `rows` | Typed rows for the selected family. An empty page is valid. |

A nonzero cursor contains the 32-byte revision followed by a u64 big-endian row offset. Access restrictions apply before rows are paged.

If permitted rows change, the service returns `conflict`. Discard that traversal and start at zero; pages from different revisions should not be combined. Reconnection also requires a new snapshot.

READ exposes account information across markets, except that an agent sees only its own grant in the grant directory. See [agents](/guides/agents).

## Missing values and history

An absent optional risk or valuation field means no valid value was available. It is not zero.

`committedAt` and `observedAt` identify Cinder's record or observation time, not an exchange's execution timestamp or a Solana block time. End-of-pages covers retained Cinder records, not necessarily every external venue event.

## SDK example

The `client` and `ctx` values follow [SDK integration](/quickstart).

```ts
export async function read(client: PrivateClient, ctx: Context, family: ReadFamily,
  cursor?: Uint8Array) {
  return client.request({ id: ctx.id, epoch: ctx.epoch, expiresAt: ctx.expiresAt,
    command: { kind: 'read', query: { family, limit: 32, cursor } } });
}
```

[WebSocket](/api/websocket) supports the same families as replacement-page subscriptions. It does not deliver every intervening event as a delta stream.
