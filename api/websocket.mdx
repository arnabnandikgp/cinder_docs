Connect with `connectWebChannel({ baseUrl, policy, core, transport: 'websocket' })`. The SDK verifies attestation, establishes the encrypted session over HTTP, then upgrades `/v1/ws` at the same origin.

Use `client.request` for the same commands and reads available over HTTP. WebSocket does not change signatures, permissions or operation IDs.

## Subscribe

An owner or current READ agent can subscribe to any [read family](/api/reads/paging), starting without a cursor. A channel supports one subscription and one iterator consumer.

The `client` and application-defined `Context` follow [SDK integration](/quickstart).

```ts
export async function subscribe(client: PrivateClient, ctx: Context) {
  const pages = await client.subscribe({ id: ctx.id, epoch: ctx.epoch,
    expiresAt: ctx.expiresAt, query: { family: 'updates', limit: 64 } });
  for await (const page of pages) {
    if (page.kind !== 'page') throw new Error('New snapshot required');
    // Replace the displayed page with page.rows.
    // Use page.next to read further rows under the same revision.
  }
}
```

The first response supplies a snapshot. Changes to permitted rows trigger replacement pages. Several changes can be combined into one newer snapshot: replace the displayed page rather than adding its rows to the previous page. This is not a notification for every intervening fill.

To recover intervening changes, page the relevant order, fill, funding or operation history. Unrelated customers' activity does not supply a global activity counter.

## Disconnect and reconnect

Permissions, session expiry and state freshness are rechecked every 500 ms, including during idle periods. Revocation, expiry, lost freshness, missing or out-of-order delivery and queue overflow close the stream.

Leaving the `for await` loop closes the subscription iterator and its channel. On closure or an iterator error, establish a freshly attested session, use current account authority and start again without a cursor to obtain a fresh snapshot.

Outstanding trades are reconciled through their original operation IDs; reconnect does not automatically resend them.

## Transport boundaries

Frames are binary and encrypted. Text messages, subprotocols, compression, private URL fields and bearer/cookie authentication are unsupported.

These subscriptions carry private account data, not public candles, ticks or orderbook feeds. See [limits](/api/limits) for capacity and [lifecycle](/api/lifecycle) for uncertain commands.
